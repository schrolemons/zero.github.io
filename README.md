# SCHNIE：Zero

SCHNIE：Zero网站的静态发布仓库，整理思想、认知与世界观相关内容。

[访问网站](http://zero.sch-nie.com/) · [仓库分类导航](https://github.com/schrolemons)

## 仓库内容

本仓库保存Hexo生成的HTML页面与静态资源。

| 路径 | 内容 |
| --- | --- |
| `index.html` | 网站首页 |
| `welcome/`、`about/` | 欢迎与介绍页面 |
| `core/`、`cogn/`、`struct/` | 核心、认知与结构相关内容入口 |
| `doc/`、`download/` | 文档与下载相关页面 |
| `posts/` | 文章页面 |
| `archives/`、`categories/`、`tags/` | 归档、分类与标签 |
| `css/`、`js/`、`image/`、`lib/` | 样式、脚本、图片与前端依赖资源 |
| `search/`、`search.json` | 站内搜索页面与索引 |

## 更新方式

正文和主题的修改应在对应的Hexo源工程中完成，生成静态页面后再发布到本仓库。当前仓库根目录保存的是发布产物，不提供独立的Hexo构建配置。

重新发布时请保留本文件，或将本文件纳入源工程的发布产物，以便保留仓库说明。
